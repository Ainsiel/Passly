# Ticket por email HTML con QR, sin PDF

El Ticket se entrega como email HTML con su código y código QR, enlazando a la vista "Mis reservas" en la web (el Ticket lo sirve el contexto Reservas). Se descartó el PDF adjunto: añade complejidad de plantillas/render sin aportar al objetivo del proyecto. Es una desviación deliberada de lo que un sistema de ticketing comercial haría.
